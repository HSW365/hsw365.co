# HSW365 Shopify theme export

This folder contains a source export of the Shopify theme **HSW365 — Clean Official Storefront (Preview)** from store `hsw365.co`.

- Shopify theme ID: `gid://shopify/OnlineStoreTheme/156395733153`
- Shopify role at export: `UNPUBLISHED` (preview)
- Exported: 2026-11-09
- Files exported: theme text/code/config/template files across assets, blocks, config, layout, locales, sections, snippets, and templates.
- Theme image asset `assets/hsw365-hero.png` is a binary Shopify-hosted asset and is documented separately; it was not copied as a binary file in this export.

## Important migration note

This is Shopify Online Store theme source (Liquid, JSON, CSS, JavaScript). It is **not** a ready-to-run standalone website. Liquid tags, Shopify product/cart/checkout objects, customer accounts, app embeds, and Shopify CDN assets depend on Shopify services. A non-Shopify host such as IONOS needs a separate storefront implementation and backend integrations.

Do not remove Shopify or change DNS until the replacement site can load products, add to cart, create payment sessions, submit orders, send confirmation emails, and route orders to fulfillment providers successfully.

## Source of truth

The live published theme at export time was **HSW365 — $20K Flagship (DRAFT)**. The newer Clean Official Storefront preview was selected for this export because it is the latest clean storefront revision. The published theme should remain untouched until the independent storefront is tested.

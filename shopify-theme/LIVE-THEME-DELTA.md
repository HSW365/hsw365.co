# Published theme comparison

Compared Shopify's published theme **HSW365 — $20K Flagship (DRAFT)** with the newer **HSW365 — Clean Official Storefront (Preview)** on 2026-11-09.

The theme file inventories and checksums are effectively the same. Two files had different contents, so the published-theme versions are preserved here as overrides:

- `live-main-overrides/sections/header-group.json`
- `live-main-overrides/templates/index.json`

Use the complete `clean-official-preview/` export as the main source tree, then apply these two override files only if recreating the published MAIN theme exactly. The clean preview remains the selected migration starting point because it is the newest clean storefront revision.

The preview export also documents one binary hero image that was not copied into GitHub.
